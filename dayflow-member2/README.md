# Dayflow - Human Resource Management System

Dayflow is a Human Resource Management System (HRMS) designed to manage employee-related activities in one place.

The system provides separate access for different user roles and helps employees manage their daily HR activities such as viewing their profile, tracking attendance, and requesting leave.

## Member 2 - Employee Module

This part of the project focuses on the Employee side of Dayflow.

### Main Features

- Employee access control
- Employee dashboard
- Employee profile management
- Attendance tracking
- Check-in and check-out
- Daily and weekly attendance views
- Employee profile updates such as phone number, address, and profile picture

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express.js
- REST API
- Postman
- Git & GitHub

## Project Goal

The goal of Dayflow is to provide a simple and organized system for managing HR activities and making employee-related tasks easier and more accessible.
